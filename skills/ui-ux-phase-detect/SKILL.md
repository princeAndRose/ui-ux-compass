# UI/UX Phase Detect

Use the current request and evidence to identify what remains: intent, structure, direction, implementation, review, or acceptance. Work can skip, combine, or return to activities.

Recommend the smallest useful next action. A new page does not imply discovery if its design is clear; dissatisfaction does not imply a complete redesign. No user-facing change means no UI workflow.

When uncertain, inspect the relevant artifact or use `ui-ux-capture-intent`. Ask only when missing information would materially change the next action. Keep phase labels internal unless useful to the user.
